- Window-only overview; the dock and its Settings tab are removed.
- Clickable 12-hour clock and battery status in the desktop menu, between
  Settings and the session/power actions. Status refreshes when the menu opens.
- PCManFM runs on demand. USB mounting and network-share support are retained.
- Remove nm-connection-editor and pulsemixer. Settings retains network and audio
  controls; nmcli remains available for advanced networking.
- Keep the default apps, keyboard shortcuts, gestures and offline Debian installer.

Fresh offline VM install: **1.748 GiB installed**, **353.2 MiB idle RAM**.
Compared with Alpha 5: 2.6 MiB less installed disk and 16.6 MiB less idle RAM.
These are the existing November 24 measurements, not a new benchmark run.
[Results and method](../guide.html#footprint).

This release promotes the already tested ISO unchanged. The embedded version is
still `dev-lean`, and its build date is November 24. Runtime source is `60df297`
plus that image label. The tagged release source also includes later host-only
labwc maintenance and automatic build/test cleanup tools. labwc remains 0.9.7
with wlroots 0.19.2; no compositor upgrade or ISO rebuild was performed.

The final-image verifier passed again: embedded runtime configuration, installer
policy, required package retention, privileged file permissions, APT-cache
budget, Twig and compositor provenance. The same image previously completed a
fresh offline UEFI VM installation and footprint measurement. Hardware support
and suspend behavior depend on the machine. This remains a prerelease; keep
backups and test before installing on an important disk. Secure Boot is unsupported.

Live console login: **user** / **live**. The offline text installer keeps disk
selection, partitioning and final erase/write confirmation interactive. The first
installed account receives sudo access. Network connections and signed APT sources
can be used after installation. The hosted Settings-only updater does not install
this compositor/package release or migrate older installations to Beta 1.

ErdOS code is MIT-licensed; labwc, wlroots, Twig and Debian packages retain their
own licenses. The source archive includes pinned vendored compositor/Twig source
and notices. Debian/Mozilla package versions are in the manifest; corresponding
package sources are available from their matching upstream archives.
