# ErdOS 1 Beta 2

November 24, 2026 · Debian 13 · amd64 · labwc / Wayland

- Replace the bundled wallpaper with the new blue starfield image.
- Signed APT updates for ErdOS desktop helpers, Settings, Twig, the custom labwc
  compositor and archive key. No updater daemon or new third-party runtime
  dependencies. Existing Debian/Mozilla sources keep their own signing keys.
- Checked one-time migration for supported legacy installations, preserving
  user settings and machine-specific hardware fixes. See [Updating ErdOS](https://patx.gitman.io/erdos/updates.md).
- Cursor theme/size, keyboard repeat/Caps Lock mapping, touchpad suppression,
  monitor enable/disable with timed rollback, and interactive Software maintenance.
- About separates the base image version from installed desktop/compositor
  versions and reports when a compositor update needs a new login session.
- Only a close button on the left for new profiles; Appearance offers Left/Right
  and optional minimize/maximize buttons.
  Super+Tab uses upstream thumbnail sizing. Existing personal layouts are retained.
- Keep the dock-free window overview, dynamic workspaces, gestures, menu status,
  default applications and offline Debian installer. No locker or idle daemon.

The image identifies itself as `1.0.0-beta.2`; custom packages use Debian version
`1.0.0~beta.2.1`. labwc stays at 0.9.7 with bundled wlroots 0.19.2. No compositor
upgrade or machine-specific suspend workaround is included.

Fresh offline VM measurement on November 24, 2026: **1.749 GiB installed** and
**351.9 MiB idle RAM**, using the unchanged published ISO. Root and EFI usage
include retained APT indexes and exclude swap; RAM is the median of five samples
after a two-minute settle. [Raw samples and image identity](../footprint.json).
See [validation](https://patx.gitman.io/erdos/testing.md) for completed checks and limits.

Live console login: **user** / **live**. The offline text installer keeps disk
selection, partitioning and final erase/write confirmation interactive. The first
installed account receives sudo access. Secure Boot is unsupported. This is a
prerelease: keep backups and test before installing on an important disk.

ErdOS code is MIT-licensed. labwc, wlroots, Twig and Debian/Mozilla packages keep
their own licenses. Matching custom-component source and build instructions are
published in the source ZIP and signed APT source archive; other package versions
are listed in the package manifest and available from their upstream archives.
