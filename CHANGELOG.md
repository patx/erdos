# Development changes

This checkout contains the current development version. Tagged releases and
older changes are available in [Git history](https://github.com/patx/erdos/tags).

- Add a Startup Applications editor for Openbox login commands, with shell
  syntax validation, previous-file backup and external-edit protection.
- Add configurable four-finger up/down swipes for the workspace overview.
- Add independent Menu settings for three-finger tap/click and Super +
  right-click. Touchpad middle-click can be restored; mouse middle-click is
  preserved.
- Keep Debian power defaults and an informational Power tab, without extra
  power services or dependencies.
- Keep one current local development ISO and remove obsolete generated images,
  build state and archived validation notes.
